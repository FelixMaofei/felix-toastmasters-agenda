# Noto Sans SC font asset

This directory vendors `@fontsource-variable/noto-sans-sc` version `5.3.0`
for deterministic, offline agenda rendering.

- Font: Noto Sans SC
- Copyright holder: Google Inc.
- Package source: https://fontsource.org/fonts/noto-sans-sc
- Package license: SIL Open Font License 1.1
- Full license text: [LICENSE](./LICENSE)

The agenda renderer embeds only the WOFF2 unicode subsets needed by the
visible meeting text. Generated agendas remain self-contained and do not
request fonts from the network.
