# 会单版式路由与主题视觉系统

整个 Skill 只有一条管道：

```text
本期接龙与明确事实
→ 确定性计算得到 computed JSON
→ 版式层选择结构 renderer
→ 主题层加入受控色彩、纹理或主题图
→ 同一 HTML 导出一页 A4 PDF 和 PNG
```

版式层和主题层都不得改写姓名、角色、顺序、时长或时间点。主题层也不得修改版式容量或用裁切伪造单页。

## 1. 版式路由

`meeting.layout` 支持 `auto`、`standard`、`feature` 和 `marathon`。

### standard：标准例会型

适用：

- 普通两小时例会；
- 备稿演讲少于 5 篇；
- 没有 15 分钟及以上的特殊环节。

骨架：

- 左侧运营信息区，组件按体量填满或流向底部；
- 右侧主时间轴；
- 不把左栏空白留成结构死角。

### feature：工作坊／重点环节型

自动触发：

- `special_segments` 中存在 15 分钟及以上的环节；或
- 存在 20 分钟及以上的备稿演讲。

骨架：

- 主时间轴优先使用左侧宽区；
- 运营组件收到右侧，超出右栏容量再流向底部；
- 重点环节使用独立大块、酒红强调和明确主讲／时长层级；
- 其他行主动退为辅助信息。

同时有多个候选重点时：

1. 用户明确指定的 `meeting.feature_item`；
2. 否则选时长最长者；
3. 时长相同时选会议中更早出现者。

`special_segments[].details` 可以提供主题、形式或过程要点，并进入专题舞台；没有详情时仍可以只显示标题、主讲人和时长。

### marathon：演讲马拉松／角色密集型

自动触发：备稿演讲达到 5 篇。

骨架：

- 主流程几乎全宽；
- 开场、演讲、点评、收尾分组；
- 演讲与点评用成组信息卡显示，不使用单一长表格；
- 幕后人员收为横向条，固定信息放在底部。

“成组”只是把同编号的演讲者和点评人建立视觉关联。时间仍显示 computed JSON 中的真实开始时间；不得把原本集中在后半场的点评挪到演讲之后。

### 路由优先级

1. 用户明确指定的 `meeting.layout`；
2. 用户明确指定了 `meeting.feature_item` -> `feature`；
3. 15 分钟及以上重点环节 -> `feature`；
4. 5 篇及以上备稿演讲 -> `marathon`；
5. 其他 -> `standard`。

固定信息组件的位置始终由当前版式决定：`standard` 使用左栏+底部，`feature` 使用右栏+底部，`marathon` 使用横向条+底部。“自动装箱”只在已选版式内分配位置，不会把三种版式压回同一骨架。

## 2. 主题视觉层

`meeting.visual_theme` 支持：

- `general`：通用品牌弧线；
- `learning`：学习、大脑、书籍、知识网络；
- `technology`：AI、数字、代码、网格与节点；
- `wellness`：健康、自然、呼吸与有机曲线；
- `voice`：声音、故事、表达与波纹；
- `leadership`：领导、影响力、向上节奏；
- `celebration`：周年、庆典、颁奖与克制金色节奏。

`auto` 先读本期主题和今日一词，再读演讲和特殊环节。本期主题的优先级高于单篇演讲。

### CSS 回退

没有主题图时，HTML 使用品牌色范围内的线条、波纹、网格或有机轮廓。它们不进入 Logo 呼吸空间，不遮挡主标题。

### 可选主题图

`meeting.theme_image` 可提供 PNG、JPG、SVG 或 WebP。适用场景：

- 用户已提供本期活动视觉；
- 当前环境可使用图片生成能力；
- 本期主题确实需要超越 CSS 纹理的艺术表达。

主题图必须：

- 不包含文字、人名、时间、二维码或 Logo；
- 不重绘 Toastmasters Logo；
- 位于页头右侧并避开官方 Logo 和主标题；
- 保持克制透明度，只做主题氛围和结构辅助。

## 3. 品牌不变项

- 只使用 Toastmasters International 官方 Logo / Wordmark / Logo Lockup；
- Logo 不重设、不改色、不拉伸、不加特效；
- 中文使用专业黑体，英文使用现代无衬线字体；
- 深蓝负责结构，暖黄负责品牌温度，酒红只负责重点；
- 不使用霓虹色、廉价渐变、卡通配色、假 Logo 或自创官方 tagline。

## 4. 验证

- 文字、姓名、时长和顺序继续以计算 JSON 为唯一真源；
- 不同版式必须对同一份计算结果保持事实一致；
- 实际 PDF 必须是 1 页 A4 竖版；
- 内容放不下时阻断导出，不裁切、不隐藏、不继续缩小字号。
