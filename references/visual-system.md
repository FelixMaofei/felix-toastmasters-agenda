# V3 单一会单视觉系统

这份文档只约束 renderer。AI 每期的语义判断见 [V3 视觉意图](v3-view-intent.md)，三层流程见 [V3 架构](v3-architecture.md)。

## 1. 设计目标

会单首先是现场运行与打印工具。视觉目标按优先级排列：

1. 重点正确；
2. 列线和边缘对齐；
3. 字号真实可读；
4. 留白服务层级；
5. 对比清楚、品牌克制。

不追求花哨特效、主题皮肤或模板数量。普通例会、重点工作坊、演讲马拉松以及中文或英文会议都使用同一语义结构和同一份 CSS。

## 2. 固定的视觉秩序

- 一页 A4 竖版，安全边距由 renderer 固定；
- 官方 Toastmasters Logo 原样使用；
- 深蓝负责结构，暖黄负责提示，酒红只用于真正重点；
- 中文和英文统一使用随 Skill 分发的 Noto Sans SC；
- 主议程始终优先，时间、环节、负责人、可选辅助列和时长共用一套全局列；
- 支持组件按真实内容自然生长，有内容才生成；
- 背景资料可读但不抢主流程；
- 页脚只显示俱乐部名称、时间闭合结果和页码。

## 3. renderer 可以响应的变量

- `density`：`comfortable / balanced / compact`，只改变行距和组间距；
- `design.text_scale`：`standard / large`，只改变受控字号档位；
- `design.contrast`：`soft / clear`，只改变允许范围内的文字和分隔对比；
- `content_emphasis`：最多一个真实环节，用字号、字重和有限颜色强调；
- `display_columns`：只显示计算真源已有数据的列；
- `component_flow`：只决定运营/背景分组和同组阅读顺序。

renderer 自己决定列宽、网格、换行和物理位置。AI 不提供坐标、列宽、组件高度、CSS class 或模板名。

## 4. 留白与组件

> 留白留在内容组之间，不留在有边框的组件里面。

允许：

- 页面边缘；
- 页头、元信息、主议程、运营信息、背景信息之间；
- 重点行内部必要的呼吸空间。

禁止：

- 为填满页面拉高短卡；
- 等高卡片导致内部空洞；
- 缺内容仍保留空栏或占位；
- 职务和姓名被大间距拆散；
- 用时长比例决定组件高度；
- 用整体缩放把第二页伪装成一页。

## 5. 字号和密度

- `compact` 不能变成“小字模式”；密度只压缩垂直间距；
- `large` 必须在最终 PNG 中肉眼明显变大，而不是只改一个无效参数；
- 同一页可有标题、重点、普通流程、辅助信息、背景资料五级字号，但普通流程和辅助信息不能退化成脚注；
- 英文长文本优先自然换行；内容无法在最低字号以上放入一页时失败并让用户取舍。

## 6. 离线资产

- HTML 只能引用随 Skill 打包并复制到本期输出目录的资源，或使用内联 data URI；
- 不联网加载字体、图片和图标；
- 不写入开发者本机绝对路径；
- PDF 必须嵌入 Noto Sans SC，不能静默回退到宿主系统字体；
- 二维码只使用用户提供的原图，不裁切、不重绘、不修复。

## 7. 真实检查

每次有意义的视觉变化都要查看真实渲染 PNG：

- 整页：重点、密度、组间留白和大块死区；
- 主流程原始尺寸：字号、列线、负责人关系和换行；
- 底部信息：自然高度、无空卡、无内容裁切；
- 最终 PDF：且仅一页 A4，字体加载，PNG 清晰。

程序只能报告技术问题，不能返回“设计好看”。样式是否成立由用户确认。

## 8. 退役内容

以下内容只存在于 V2 历史回放，不得进入新任务：

- `standard / feature / marathon` 版式路由；
- `classic / editorial` 双 renderer；
- 自动主题皮肤和主题插图；
- 按时长放大重点块；
- `flex: 1` 或等高卡片填满页面；
- 每期由模型自由重写 HTML/CSS。
